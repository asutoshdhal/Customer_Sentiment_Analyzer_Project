# Customer Sentiment Analyzer (Python + TextBlob)

## Description
This project performs sentiment analysis on customer reviews without using ML models.  
It classifies reviews into Positive, Negative, and Neutral, extracts frequent keywords, and provides business insights.

## How to Run
1. Install Python 3
2. Install dependencies: `pip install pandas textblob`
3. Navigate to `src` folder and run: `python sentiment_analysis.py`
4. Check the `output` folder for results (sentiment_results.csv & frequent_keywords.csv)

## Folder Structure
- src/: Python script
- data/: Sample review data
- output/: Analysis results
- docs/: Project report

## Features
- Sentiment classification using TextBlob
- Frequent keyword extraction
- Actionable business insights
